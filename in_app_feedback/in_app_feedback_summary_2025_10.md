# In-App Feedback Summary - October 2025

**Period:** October 1, 2025 - October 31, 2025
**Channel:** in_app_feedback

**Channel context:** The `in_app_feedback` Slack channel does **not** contain a balanced sample of all user feedback. It primarily aggregates:

- **FEEDBACK_TYPE: Account Deletion Request**
- **Negative feedback:** users selecting the `:(` emoji in the in‑app feedback widget
- **Positive feedback:** users selecting the `:)` emoji in the in‑app feedback widget (a minority of events)

This means that **most messages visible in this channel are either account deletion requests or negative feedback**, so the analysis below reflects a **negatively skewed subset** of overall user sentiment.

## Opportunities (Feature Development Suggestions)

1. **Feed/Discovery Feature**
   - User 1290760 (DE): "Ich würde es schöner finden, wenn es so einen feed wie bei Insta gibt, durch den man stöbern und neue Materialien entdecken kann. Zuerst die der gefolgten und dann neue Inspirationen" ("I would find it nicer if there was a feed like Instagram where you can browse and discover new materials. First those from followed creators and then new inspirations")
   - User 4249060 (GR): Similar request for more diverse carousel displays showing new creators and less common languages

2. **School Account Collaboration Features**
   - User 4077111 (DE): Request for a shared wishlist or cart feature for school accounts, so teachers can add items that only the admin can purchase

3. **Filter Improvements**
   - User 4086975 (DE): Request for multiple filter selection instead of entering filters individually, and toggle for automatic download

4. **Missing Subject Categories**
   - User 2263194 (DE): "Werken und Gestalten" (Arts and Crafts) and "Ernährung und Soziales" (Nutrition and Social Studies) are missing from the subject search function

5. **Author-Specific Features**
   - User 4249060 (GR): Request for fairer and more diverse carousel display to highlight new creators and less common languages

6. **Turkish Language Support**
   - User 4412215 (DE): "Es bietet keine Unterstützung für die türkische Sprache" ("It doesn't support Turkish language")

7. **Email Notification Controls**
   - User 2778976 (DE): Request to disable daily emails about downloads of uploaded materials

8. **Accessibility Improvements**
   - User 4402787 (DE): Request for screen reader support and accessibility improvements for blind users
